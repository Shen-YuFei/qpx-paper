# Code Availability

The QPX specification, schemas, converters and Python package are available at
https://github.com/bigbio/qpx under the Apache 2.0 licence; this paper describes release
1.4.0 [TODO: release date], which writes specification 1.3, available from PyPI and as the
container image `ghcr.io/bigbio/qpx:1.4.0` [TODO: Zenodo DOI; Zenodo archiving is not yet

versions used], and nf-core/mhcquant at https://github.com/nf-core/mhcquant [TODO: version].

including the QPX Explorer, at https://github.com/bigbio/quantms-portal, and the QPX UI
desktop viewer at https://github.com/bigbio/qpxui under the Apache 2.0 licence [TODO: version
