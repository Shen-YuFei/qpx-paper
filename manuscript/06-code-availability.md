# Code Availability

The QPX specification, schemas, converters and Python package are available at
https://github.com/bigbio/qpx under the Apache 2.0 licence; this paper describes release
1.4.0 [TBD: release date], which writes specification 1.3, available from PyPI and as the
container image `ghcr.io/bigbio/qpx:1.4.0` [TBD: Zenodo DOI]. The processing workflows are available at
https://github.com/bigbio/quantms and https://github.com/bigbio/quantmsdiann [TBD: versions], and nf-core/mhcquant at https://github.com/nf-core/mhcquant [TBD: version].
pmultiqc is available at https://github.com/bigbio/pmultiqc, the quantms portal,
including the QPX Explorer, at https://github.com/bigbio/quantms-portal, and the QPX UI
desktop viewer at https://github.com/bigbio/qpxui under the Apache 2.0 licence [TBD: version cited]. The scripts that build the figures, the
supplementary tables and the benchmark, the validation scripts and an example Python script for
reading the corpus are at https://github.com/Shen-YuFei/qpx-paper [TBD: public repository and Zenodo DOI].
